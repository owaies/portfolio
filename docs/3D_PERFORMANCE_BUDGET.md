# Portfolio 3D performance budget

The portfolio includes React Three Fiber and Three.js scenes alongside motion effects.

## Scene discipline
- Load heavy 3D assets only when the related experience needs them.
- Avoid unnecessary duplicate model instances.
- Dispose resources when scenes are permanently removed.
- Prefer compressed, appropriately sized assets over oversized source files.

## Interaction
Keep pointer and scroll-driven effects responsive on lower-powered laptops and mobile devices.

## Accessibility
Respect reduced-motion preferences and keep essential portfolio information available without 3D effects.

## Verification
Check the cinematic sections at desktop, tablet, and mobile widths after every major 3D change.
