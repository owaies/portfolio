# Accessibility review checklist

Use this checklist when changing the portfolio UI.

## Keyboard
- All interactive controls can be reached with the keyboard.
- Focus indicators remain visible.
- Dialogs and menus can be opened and closed without a pointer.

## Semantics
- Images have meaningful alternative text when needed.
- Headings follow a logical hierarchy.
- Links and buttons have clear accessible names.

## Motion
- Decorative animation does not block interaction.
- Reduced-motion preferences are respected.
- Auto-playing visual effects do not create essential information only through motion.

## Responsive behavior
- Content remains readable without horizontal scrolling.
- Touch targets remain usable on small screens.
