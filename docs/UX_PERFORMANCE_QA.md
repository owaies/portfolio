# Portfolio UX Performance QA

The portfolio contains multiple cinematic UI experiences, responsive art direction, 3D assets, and motion-heavy sections.

## Desktop checks

Verify the hero, navigation, projects, admin/editor pages, and UI-experience switching at a normal desktop viewport. Confirm that motion does not create clipped text, overlapping controls, or unexpected scroll containers.

## Mobile checks

Test narrow phone widths and touch interaction. Check the project grid, hero composition, loading experience, and scroll-driven sections without relying on a mouse hover state.

## Accessibility

Run the reduced-motion path and confirm that meaningful content remains available without animation. Check keyboard focus order, semantic labels, and error-state announcements on interactive forms.
