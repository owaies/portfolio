# Developer Onboarding

1. Clone the repository.
2. Copy `.env.example` to `.env.local` and provide the public Supabase connection values.
3. Install dependencies with npm.
4. Run `npm run typecheck`, `npm run lint`, and `npm run build`.
5. Start the development server with `npm run dev`.
6. Review `README.md`, `CONTRIBUTING.md`, and `docs/architecture.md` before changing application boundaries.

Keep changes focused, preserve existing conventions, and use the repository quality workflow as the final validation gate.
