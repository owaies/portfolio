# Mobile QA

Check the portfolio at narrow widths before shipping UI changes.

- Verify the public navigation opens, closes, and restores focus correctly.
- Check that primary actions remain reachable without horizontal scrolling.
- Confirm text wraps without clipping on small screens.
- Check project cards and media for overflow.
- Verify the contact form remains usable with the on-screen keyboard.
- Test portrait and landscape layouts where practical.
- Confirm reduced-motion behavior still leaves the interface understandable.
