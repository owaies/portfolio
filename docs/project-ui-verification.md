# Project UI verification

The portfolio contains multiple visual experiences, so project-section changes should be verified in each relevant presentation mode.

## Desktop
- Check project card alignment and spacing.
- Verify project imagery remains visible.
- Confirm hover and scroll interactions do not obscure project information.

## Mobile
- Verify cards fit the viewport without horizontal overflow.
- Confirm touch interactions remain usable.
- Check that project titles, descriptions, and calls to action remain readable.

## Release
Review the project section after every major animation or layout change at both desktop and mobile widths.
