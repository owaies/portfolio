# SEO Checklist

For public-page changes, verify the following:

- Each important page has a meaningful title and description.
- Canonical URLs point to the production origin.
- `robots` keeps admin and authentication routes out of indexing.
- The sitemap contains the homepage and published project routes.
- Project metadata is derived from actual stored project content.
- Open Graph and social preview metadata remain accurate.
- Structured data contains only verified identity and profile information.
- Never add fabricated keywords, achievements, or claims for search visibility.
